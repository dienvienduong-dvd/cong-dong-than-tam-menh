# Digitize Formats — Cách Số Hóa Từng Loại Sản Phẩm
# Tài liệu tham chiếu nội bộ cho Skill Hệ Sinh Thái Số

---

## NGUYÊN TẮC SỐ HÓA

1. **Tạo ra được trong 1–7 ngày** — không phải dự án dài hạn
2. **Dùng công cụ miễn phí trước** — chỉ trả tiền khi có doanh thu
3. **Giao nhận tự động** — một lần tạo, bán mãi mãi
4. **Bắt đầu đơn giản nhất có thể** — Google Drive + PDF đã đủ để bắt đầu

## THEO TỪNG LOẠI SẢN PHẨM

### LOẠI 1: PDF / Ebook / Checklist / Tài liệu
```
Dùng cho: Lead Magnet, Tripwire, tài liệu Core Offer, Downsell

Công cụ tạo:
· Canva (canva.com) — thiết kế đẹp, free, xuất PDF ngay
· Notion (notion.so) — viết nhanh, xuất PDF, free
· Google Docs → File → Download PDF — đơn giản nhất

Quy trình tạo:
1. Viết nội dung trong Google Docs / Notion
2. Thiết kế layout trong Canva (dùng template có sẵn)
3. Xuất PDF
4. Upload lên Google Drive → Copy link share (Anyone with link can view)
5. Đặt link vào form hoặc email tự động

Thời gian: 4–8 tiếng cho 20–30 trang
Chi phí: 0đ
Giao nhận: Link Google Drive (gửi tự động qua email hoặc Zalo)
```

### LOẠI 2: Video bài giảng / Record màn hình
```
Dùng cho: Downsell (khóa tự học), Core Offer (record buổi học), Tầng 1 (video ngắn)

Công cụ tạo:
· Loom (loom.com) — record màn hình + webcam, free 5 phút/video
· OBS Studio (obsproject.com) — miễn phí, không giới hạn thời gian
· Zoom record — record buổi học 1:1 lưu cloud hoặc local
· Google Meet — record tự động lưu Google Drive (cần tài khoản trả phí)

Quy trình tạo:
1. Chuẩn bị slide (Canva / Google Slides)
2. Mở OBS / Loom → Record màn hình + giọng nói
3. Upload lên Google Drive (miễn phí) hoặc YouTube (unlisted)
4. Copy link → đặt vào tài liệu hướng dẫn / email / Gumroad

Thời gian: 1–2 tiếng/video 20–30 phút
Chi phí: 0đ (OBS) hoặc 0đ (Loom free tier)
Giao nhận: Link Drive/YouTube unlisted → gửi sau khi thanh toán
```

### LOẠI 3: Bộ câu hỏi / Trắc nghiệm / Luyện tập
```
Dùng cho: Lead Magnet, Tripwire, Downsell, thành phần trong Core Offer

Công cụ tạo:
· Google Forms — miễn phí, dễ dùng, có chấm điểm tự động
· Anki (apps.ankiweb.net) — flashcard, spaced repetition, miễn phí
· Notion database — linh hoạt hơn Google Form

Quy trình tạo (Google Form):
1. Tạo Google Form → chọn Quiz mode
2. Nhập câu hỏi + đáp án + giải thích
3. Bật "Show correct answers" sau khi nộp
4. Copy link → share

Thời gian: 2–4 tiếng cho 50–100 câu
Chi phí: 0đ
Giao nhận: Link Google Form (public)
```

### LOẠI 4: Template / Công cụ thực hành
```
Dùng cho: Tripwire, Downsell, thành phần Value Stack trong Core Offer

Công cụ tạo:
· Google Sheet — bảng tính, theo dõi, tính toán
· Notion template — hệ thống quản lý, lịch học, tracker
· Canva template — thiết kế có thể chỉnh sửa

Quy trình tạo (Google Sheet):
1. Tạo file Google Sheet
2. Thiết kế template (có hướng dẫn điền vào)
3. File → Share → Copy link (Anyone with link can view)
4. Người mua copy về Drive của họ để dùng

Quy trình tạo (Notion):
1. Tạo Notion page → thiết kế template
2. Share → Publish to web
3. Người mua "Duplicate" template về workspace của họ

Thời gian: 2–6 tiếng
Chi phí: 0đ
```

### LOẠI 5: Cộng đồng / Group hỗ trợ
```
Dùng cho: Tầng 5 Retention, thành phần trong Core Offer

Nền tảng:

Telegram (khuyến nghị cho người mới bắt đầu):
· Miễn phí hoàn toàn
· Tạo group riêng tư → invite link
· Có thể set link hết hạn (bảo mật)
· Bot tự động: thêm thành viên, kick hết hạn

Zalo Group:
· Phổ biến hơn với người dùng VN
· Dễ dùng hơn cho khách hàng lớn tuổi
· Giới hạn 1.000 thành viên (miễn phí)

Skool (skool.com):
· Nền tảng chuyên cho community có phí
· Có gamification, course, calendar
· Giá: $99/tháng → chỉ dùng khi community đã lớn

Quy trình setup Telegram group:
1. Tạo group → set Private
2. Tạo invite link có hết hạn (7 ngày)
3. Gửi link sau khi khách thanh toán
4. Kick thành viên hết hạn hàng tháng (có thể dùng bot)
```

### LOẠI 6: Email tự động
```
Dùng cho: Tầng 5 Retention (email sequence 3 email)

Công cụ:
· Brevo (brevo.com) — free 300 email/ngày, không giới hạn contact
· Mailchimp — free 500 contact, 1.000 email/tháng
· Resend (resend.com) — dành cho developer, 3.000 email/tháng free

Quy trình setup Brevo (đơn giản nhất):
1. Đăng ký Brevo → xác minh domain email
2. Tạo Contact list
3. Tạo Automation → trigger "Contact added to list"
4. Thêm 3 email theo thứ tự:
   · Email 1: gửi ngay (delay 0)
   · Email 2: delay 2 ngày
   · Email 3: delay 4 ngày (tính từ đầu)
5. Kết nối form đăng ký → tự động thêm vào list → trigger sequence

Chi phí: 0đ (free tier)
Thời gian setup: 2–4 tiếng
```

### LOẠI 7: Thanh toán & Giao nhận tự động
```
Dùng cho: Tất cả các tầng có sản phẩm trả phí

Công cụ:

Sepay (sepay.vn) — KHUYẾN NGHỊ cho VN:
· Miễn phí setup
· Kết nối ngân hàng → tạo QR tự động
· Webhook: khi nhận tiền → trigger giao hàng tự động
· Tích hợp được với website / Zalo / Telegram

Gumroad (gumroad.com):
· Dành cho file số (PDF, video, template)
· Khách trả → nhận link download tự động
· Phí: 10% mỗi giao dịch
· Không cần website, không cần code

Google Drive + form thủ công:
· Khách điền form đăng ký
· Mình check → gửi link Drive thủ công
· Phù hợp khi mới bắt đầu, chưa có hệ thống

Quy trình Gumroad (đơn giản nhất):
1. Đăng ký Gumroad → kết nối Paypal hoặc Stripe
2. Tạo product → upload file → đặt giá
3. Copy link sản phẩm → share lên mạng xã hội
4. Khách mua → nhận file tự động → mình nhận tiền
```
